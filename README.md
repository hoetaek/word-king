# 낱말킹 (WORD BATTLE)

글자판에 숨은 낱말을 뜻을 보고 찾는 두 사람 대결 게임입니다. 초등 1~2 · 3~4 · 5~6학년 낱말이 들어 있습니다.

게임의 동작과 낱말은 그대로입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임의 화면과 동작 |
| `data.json` | 낱말과 뜻. 한 줄이 낱말 하나입니다(`word` 낱말, `meaning` 뜻) |

## 실행 방법

`index.html`을 두 번 눌러 열면 게임이 시작되지 않습니다. 주소가 `file://`로 시작하면 브라우저가 `data.json`을 읽지 못하게 막기 때문입니다. 내 컴퓨터에서 웹 서버를 켜서 엽니다.

이 폴더에서 아래 명령을 실행하고, 나오는 `http://localhost:숫자` 주소를 브라우저로 엽니다.

```
npx serve
```

## 우리 반 낱말로 바꾸기

`data.json`의 낱말과 뜻을 고치고 브라우저를 새로 고칩니다.

```json
{ "word": "가꾸다", "meaning": "식물이나 장소를 예쁘게 만들다" }
```

학년군은 세 묶음입니다: `grade1_2`, `grade3_4`, `grade5_6`.
